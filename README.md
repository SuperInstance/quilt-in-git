# quilt-in-git

**The entire simplified Quilt lives inside a plain Git repository: dials are
files, ticks are commits, rewind is checkout, and Git hooks are the runtime.**
Every cell is a directory under `cells/`; its state is 16 dial files (one
float each) plus a body. Changing a dial and committing it is a *tick*; a
`post-commit` hook turns that tick into a receipt, an entanglement cascade,
and a watch-log line. Because everything is ordinary Git content, the repo is
simultaneously the Sheet, the journal, and the collaboration bus — clone,
push, bundle, branch, and time travel all come free.

## Layout

```
cells/<alias>/dials/0..15   16 dials, one float per file
cells/<alias>/body          the cell's content
cells/<alias>/links         optional; lines of "<src_alias> <weight>"
.quilt/bin/quilt-init       bootstrap (run once per clone)
.quilt/bin/quilt-tick       convenience: set one dial + commit
.quilt/bin/quilt-cascade    recompute dial 14 from links
.quilt/bin/quilt-receipt    write .quilt/receipts/<short>.json
.quilt/bin/quilt-publish    snapshot dials + vitals into refs/quilt/*
.quilt/bin/quilt-read-dials print alias:dial:value lines from a ref
.quilt/hooks/               pre-commit, post-commit (generated by quilt-init)
.quilt/receipts/            one JSON receipt per tick commit
.quilt/watch.log            one "tick <short> <short> <cells>" line per tick
refs/quilt/dials            orphan snapshot: ONLY the fleet's dial files
refs/quilt/HEAD             orphan snapshot: dials + last_receipt + watch_tail
```

## Dial map

| dial | name          | meaning                                                        |
|------|---------------|----------------------------------------------------------------|
| 0–13 | generic       | free per-cell knobs (budget, health, …)                        |
| 1    | OBSTRUCTION   | friction of the cell; feeds linked cells' entanglement          |
| 14   | ENTANGLEMENT  | derived: `max(src dial 1 × weight)` over the cell's links       |
| 15   | FREEZE        | `> 0.5` = frozen; pre-commit rejects changes to that cell       |

## The minimal loop

```bash
git init q && cd q
# bring in the runtime (or clone this repo) and activate it
/path/to/quilt-in-git/.quilt/bin/quilt-init     # sets core.hooksPath

mkdir -p cells/auth/dials && echo 0.11 > cells/auth/dials/1
git add cells && git commit -m "cells: seed auth"   # already a tick

echo 0.42 > cells/auth/dials/0
git add cells/auth/dials/0
git commit -m "tick: lower auth budget"          # receipt + watch line appear

cat .quilt/receipts/*.json                       # proof of what happened
tail -f .quilt/watch.log                         # live tick stream
git log -p -- cells/auth/                        # history of nudges
git checkout <old-hash> -- cells/auth/           # rewind just that organ

# from anywhere in the fleet — vital signs without cloning:
git ls-remote origin 'refs/quilt/*'              # refs answer: no clone needed
git fetch origin refs/quilt/dials                # every dial, kilobytes only
.quilt/bin/quilt-read-dials FETCH_HEAD           # "auth:1:0.11" per line
```

Or with the helper: `.quilt/bin/quilt-tick auth 0 0.42`.

## Runtime semantics

- **Receipts.** `post-commit` writes `.quilt/receipts/<short>.json`:
  `{commit, changed_cells, key_dials{<alias>{obstruction,freeze}}, ts}`.
  `ts` is the git commit time (`git log -1 --format=%ct`), never wall clock,
  so receipts reproduce deterministically from history.
- **Cascade.** For every `cells/<alias>/links`, dial 14 becomes
  `max(src.dial1 × weight)` over its lines, rounded to 4 decimals (awk).
  Missing sources count as 0. One pass, sorted glob order, no transitive
  propagation — deterministic. If cascade changed any dial file, the hook
  auto-commits `quilt: cascade after <short>` with `--no-verify`.
- **Freeze.** `pre-commit` reads the *committed* dial 15 of each staged
  cell; `> 0.5` rejects the commit with `ERROR: cell <alias> is frozen`.
  Staged paths that are only `dials/15` are exempt, so freeze/unfreeze is
  always possible (as its own commit). Cascade auto-commits bypass the
  check (`--no-verify`), like the design doc's auto-freeze pattern.
- **Watch.** One line per tick: `tick <short> <receipt-hash> <cells>`.
  Commits touching no `cells/` path produce nothing — the journal stays
  quiet.
- **Live-state refs.** Every tick's `post-commit` also runs
  `.quilt/bin/quilt-publish`, which writes two parentless ("orphan")
  snapshot commits built in a private index (`read-tree --empty`, reuse the
  committed dial blobs, `write-tree`, `commit-tree` with no parent) and
  moves the refs:
  **`refs/quilt/dials`** holds ONLY the dial files of HEAD — no bodies, no
  links, no history — so an agent can `git fetch origin refs/quilt/dials`
  and read the entire fleet's dial state in kilobytes
  (`.quilt/bin/quilt-read-dials <ref>` prints `alias:dial:value` lines via
  `ls-tree` + `cat-file`, no checkout).
  **`refs/quilt/HEAD`** holds the dials plus `.quilt/live/last_receipt`
  (the newest receipt JSON, found via the last watch line) and
  `.quilt/live/watch_tail` (last 20 watch lines) — the vital signs at a
  glance; `git ls-remote origin "refs/quilt/*"` answers before any fetch.
  Snapshots inherit the tick commit's dates, so republishing the same HEAD
  is a no-op; the refs are replaced (not appended to) each tick and stale
  snapshots leave with `git gc`.

## Honest limits

1. **`core.hooksPath` is local config.** Hooks travel with the repo but are
   inert in a fresh clone; every clone must re-run `.quilt/bin/quilt-init`.
2. **Receipts use git commit time, not wall clock.** Deterministic, but a
   rebased/amended history gets new receipt times for free.
3. **Freeze is a convention enforced at pre-commit, not security.**
   `git commit --no-verify` (and the cascade path) bypasses it.
4. **The cascade commit sweeps any dirty `cells/` files** that were left
   uncommitted when a tick lands.
5. **`receipts/` and `watch.log` are working-tree artifacts** until someone
   commits them; `git add .quilt && git commit` folds the journal in (such
   commits are silent by design).
6. **`refs/quilt/*` answer "what is the state NOW", never "what changed".**
   They are parentless snapshots replaced on every tick — the delta
   question is the main history's job. Their `last_receipt`/`watch_tail`
   come from the (possibly uncommitted) working-tree journal, so they
   describe the live clone that last ticked.

## Pins

`tests/pins_quiltgit.sh` — plain bash + git, no network, scratch repos under
`/tmp`. P1–P6: receipt+watch on dial commit, freeze enforcement, cascade,
rewind, clone-needs-quilt-init, non-cell commits stay silent. P10–P12
(numbering continues the wave-3 sequence; P7–P9 live on a sibling lane):
`refs/quilt/dials` exists after a tick with the ticked value and no parent
commit, its tree is dials-only (no cell bodies), and `refs/quilt/HEAD`
carries `last_receipt` + `watch_tail` and answers `git ls-remote .`.
Logs in `pins/`.
