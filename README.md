# quilt-in-git

**The entire simplified Quilt lives inside a plain Git repository: dials are
files, ticks are commits, rewind is checkout, and Git hooks are the runtime.**
Every cell is a directory under `cells/`; its state is 16 dial files (one
float each) plus a body. Changing a dial and committing it is a *tick*; a
`post-commit` hook turns that tick into a receipt, an entanglement cascade,
and a watch-log line. Because everything is ordinary Git content, the repo is
simultaneously the Sheet, the journal, and the collaboration bus — clone,
push, bundle, branch, and time travel all come free.

## Layout

```
cells/<alias>/dials/0..15   16 dials, one float per file
cells/<alias>/body          the cell's content
cells/<alias>/links         optional; lines of "<src_alias> <weight>"
.quilt/bin/quilt-init       bootstrap (run once per clone)
.quilt/bin/quilt-tick       convenience: set one dial + commit
.quilt/bin/quilt-cascade    recompute dial 14 from links (reads the index)
.quilt/bin/quilt-receipt    write .quilt/receipts/<short>.json
.quilt/bin/quilt-export     write the whole quilt to a git bundle (one file)
.quilt/bin/quilt-import     land a bundle in a clone: refs + hooks + journal
.quilt/bin/quilt-focus      sparse-checkout ONE cell + .quilt/ (--off undoes)
.quilt/hooks/               pre-commit, post-commit (generated by quilt-init)
.quilt/receipts/            one JSON receipt per tick commit
.quilt/watch.log            one "tick <short> <short> <cells>" line per tick
demos/airgap.sh             narrated export → destroy → import round-trip
```

## Dial map

| dial | name          | meaning                                                        |
|------|---------------|----------------------------------------------------------------|
| 0–13 | generic       | free per-cell knobs (budget, health, …)                        |
| 1    | OBSTRUCTION   | friction of the cell; feeds linked cells' entanglement          |
| 14   | ENTANGLEMENT  | derived: `max(src dial 1 × weight)` over the cell's links       |
| 15   | FREEZE        | `> 0.5` = frozen; pre-commit rejects changes to that cell       |

## The minimal loop

```bash
git init q && cd q
# bring in the runtime (or clone this repo) and activate it
/path/to/quilt-in-git/.quilt/bin/quilt-init     # sets core.hooksPath

mkdir -p cells/auth/dials && echo 0.11 > cells/auth/dials/1
git add cells && git commit -m "cells: seed auth"   # already a tick

echo 0.42 > cells/auth/dials/0
git add cells/auth/dials/0
git commit -m "tick: lower auth budget"          # receipt + watch line appear

cat .quilt/receipts/*.json                       # proof of what happened
tail -f .quilt/watch.log                         # live tick stream
git log -p -- cells/auth/                        # history of nudges
git checkout <old-hash> -- cells/auth/           # rewind just that organ
```

Or with the helper: `.quilt/bin/quilt-tick auth 0 0.42`.

## Runtime semantics

- **Receipts.** `post-commit` writes `.quilt/receipts/<short>.json`:
  `{commit, changed_cells, key_dials{<alias>{obstruction,freeze}}, ts}`.
  `ts` is the git commit time (`git log -1 --format=%ct`), never wall clock,
  so receipts reproduce deterministically from history.
- **Cascade.** For every `cells/<alias>/links`, dial 14 becomes
  `max(src.dial1 × weight)` over its lines, rounded to 4 decimals (awk).
  Missing sources count as 0. One pass, sorted glob order, no transitive
  propagation — deterministic. If cascade changed any dial file, the hook
  auto-commits `quilt: cascade after <short>` with `--no-verify`.
- **Freeze.** `pre-commit` reads the *committed* dial 15 of each staged
  cell; `> 0.5` rejects the commit with `ERROR: cell <alias> is frozen`.
  Staged paths that are only `dials/15` are exempt, so freeze/unfreeze is
  always possible (as its own commit). Cascade auto-commits bypass the
  check (`--no-verify`), like the design doc's auto-freeze pattern.
- **Watch.** One line per tick: `tick <short> <receipt-hash> <cells>`.
  Commits touching no `cells/` path produce nothing — the journal stays
  quiet.

## Air-gap transport: bundles

Two agents that never share a remote (or a network) still sync: the whole
quilt — branch, `refs/quilt/*`, history — packs into one file, and the
journal regenerates on the far side from history alone.

```bash
# near side
git add .quilt && git commit -m "journal"   # fold the journal in (optional)
.quilt/bin/quilt-export /usb/quilt.bundle   # complete bundle: no prereqs

# ... carry the file across the air gap by any medium ...

# far side
git clone /usb/quilt.bundle far/ && cd far
.quilt/bin/quilt-import /usb/quilt.bundle
```

`quilt-import` verifies the bundle, fetches `refs/quilt/*` (a plain clone
carries only heads), checks out the bundled branch, re-runs `quilt-init`,
then **regenerates** `.quilt/receipts/` and `watch.log` by walking every
commit oldest-first and re-running the receipt logic — and verifies the
result byte-identical to the journal carried inside the bundle. Receipts
use commit time and tree state, never wall clock, so the journal is a pure
function of history: same commits in, same journal out, on any machine.
`demos/airgap.sh` tells the whole story — including deleting the original
repo before importing (the bundle is the only surviving copy).

A bundle is a snapshot, not a channel: it syncs one way, once. Two sides
that keep ticking diverge and reconcile the ordinary git way (fetch,
rebase, merge) — with the journal regenerated per side afterwards.

## Focus: working one organ

An agent working ONE organ should not hold the whole body:

```bash
.quilt/bin/quilt-focus auth    # worktree = cells/auth/ + .quilt/ only
.quilt/bin/quilt-focus --off   # full body back, nothing lost
```

`quilt-focus` is sparse-checkout underneath: it flips skip-worktree bits in
the index; no blob is ever deleted. **The received guarantee:** focus is
worktree-only. A focused agent reads and writes its own cell's dials (they
are materialized), and the cascade still sees EVERY cell's dial values,
because `quilt-cascade` reads the **index** (`git show :cells/...`), not
the worktree. Cascade updates to out-of-focus cells are staged straight
into the index (`update-index --cacheinfo`) and ride the next commit —
inspect them with `git ls-files -s cells/<alias>/dials/14` +
`git cat-file -p <sha>`, no unfocus needed. (The wave-2 cascade did read
the worktree and would have gone blind under focus — the claim was tested,
found false, and the hook fixed; pin P14 holds it true.) `quilt-tick`
refuses to tick a cell that is not in focus rather than writing into a
hole the sparse worktree cannot see.

## Honest limits

1. **`core.hooksPath` is local config.** Hooks travel with the repo but are
   inert in a fresh clone; every clone must re-run `.quilt/bin/quilt-init`
   (`quilt-import` does it for you).
2. **Receipts use git commit time, not wall clock.** Deterministic, but a
   rebased/amended history gets new receipt times for free.
3. **Freeze is a convention enforced at pre-commit, not security.**
   `git commit --no-verify` (and the cascade path) bypasses it.
4. **The cascade commit sweeps any dirty materialized `cells/` files** that
   were left uncommitted when a tick lands. Out-of-focus cells are never
   swept — only the cascade's own index updates land for them.
5. **`receipts/` and `watch.log` are working-tree artifacts** until someone
   commits them; `git add .quilt && git commit` folds the journal in (such
   commits are silent by design).
6. **A bundle is a snapshot, not a channel.** One direction, one shot;
   diverging sides reconcile with ordinary git, then regenerate journals.
7. **Focus from a clean tree.** Git (rightly) refuses to drop worktree
   files with uncommitted changes when focusing; commit or stash first.
8. **Journal regeneration assumes stable short-hash abbreviations.**
   Receipt filenames and watch lines use `git rev-parse --short`; at demo
   scale both sides agree, but a repository large enough to lengthen
   abbreviations would regenerate different (still valid) names.

## Pins

`tests/pins_quiltgit.sh` — plain bash + git, no network, scratch repos under
`/tmp`. Six wave-2 pins: receipt+watch on dial commit, freeze enforcement,
cascade, rewind, clone-needs-quilt-init, non-cell commits stay silent.
`tests/pins_w3c.sh` adds three wave-3c pins: P13 bundle air-gap round-trip
(export, destroy the source, import, journal regenerates identically),
P14 sparse focus (other cells' bodies absent from the worktree, yet a
focused tick still cascades and the other cell's dial lands in the index),
P15 `--off` restores the full body. Logs in `pins/`.
